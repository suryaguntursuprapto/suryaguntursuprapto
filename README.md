Information Technology graduate from **Universitas Muhammadiyah Yogyakarta (UMY)** with a strong foundation in full-stack web development and software engineering. **Certified Web Developer by BNSP**. Passionate about turning ideas into scalable, functional, and user-friendly digital products.

- 🎨 I care about UI/UX as much as backend architecture
